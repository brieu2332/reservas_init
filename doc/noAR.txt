
# 1. Ative o ambiente virtual
venv\Scripts\activate

# 2. install requirements
pip install -r requirements.txt

# 3. Inicie o servidor Flask
python main.py

Navegue até a pasta do protótipo do front-end:


Bash

cd frontEnd/01-prototipo-interface
Execute o comando para iniciar o servidor web simples:

Bash

python -m http.server
O front-end estará rodando em http://localhost:8000. Mantenha este terminal aberto.

3. Acessar a Aplicação
Abra seu navegador de internet.

Acesse o endereço do front-end: http://localhost:8000
